# 🎰 SimpleCasino

Простой и легкий плагин на слот-машину (казино) с анимированным GUI-меню для серверов Minecraft.

* **Поддерживаемые версии:** 1.21.4 – 26.3
* **Ядра:** Paper, Purpur, Spigot
* **Шанс любого выигрыша:** 36%

---

## 📦 Зависимости (Обязательно)

Для работы плагина на сервере должны быть установлены:
1. **[Vault](https://spigotmc.org)** (или **VaultUnlocked** для новых версий)
2. **Любой плагин на экономику** (например, **EssentialsX** или **CMI**)

---

## ⚙️ Установка

1. Скачайте архив из раздела **[Releases](../../releases)** и извлеките из него файл `SimpleCasino-1.0.0.jar`.
2. Поместите `SimpleCasino-1.0.0.jar` в папку `plugins/` вашего сервера.
3. Убедитесь, что плагины экономики и Vault уже установлены.
4. Перезапустите сервер.

---

## 🎮 Команды и права

| Команда | Описание | Право (Permission) | По умолчанию |
| :--- | :--- | :--- | :--- |
| `/casino <ставка>` | Списывает сумму и запускает слот-машину | `simplecasino.use` | Доступно всем |

---

## 🎲 Механика и шансы

* **Выигрыш за 2 одинаковых символа подряд** (слева или справа): множитель **1.5x** (шанс 32%).
* **Выигрыш за 3 одинаковых символа в ряд:** множители от **2x** до **10x** в зависимости от предмета (шанс 4%).
* **Минимальная ставка:** 50$ *(настраивается в `config.yml`)*.
* **Максимальная ставка:** 50 000$ *(настраивается в `config.yml`)*.
